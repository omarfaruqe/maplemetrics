# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
on the repository page choose **Security**, then **Report a vulnerability**. Say what you found,
how to reproduce it and which version you tested. This is a portfolio project maintained by one
person, so there is no formal response time, but reports are read and taken seriously.

## Scope

MapleMetrics is read-only and holds only public data from Statistics Canada and the Bank of
Canada. It has no user accounts, no user content and no payments. The things worth reporting are
cross-site scripting, injection, anything that exposes the server or its configuration, and
weaknesses in the deployment files.

See [docs/security.md](docs/security.md) for what is already in place.
